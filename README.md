# VSM Coach

Mappe del flusso di valore in sanità (metodo Jimmerson), con coach.
App interamente lato client: le mappe restano sul dispositivo (IndexedDB), niente server.

- App: `index.html` — installabile come PWA ("Aggiungi a Home"), funziona offline.
- Copia di scorta in un file solo: `offline.html` (da scaricare e aprire senza rete).

Sorgente di lavoro: `~/Scrivania/vsm-coach`.
